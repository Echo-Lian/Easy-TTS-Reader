# Easy TTS Reader

A free, AI-powered Text-to-Speech (TTS) application that convert pdf file to natural-sounding audios with a concise and intuitive interface. Users can easily listen to the the generated audio on their own devices, without the need for any subscription or API keys.

## Helpful tips
### Find pdf files via your Zotero library.
1. `open Zotero/storage/23BRS2F8/*.pdf` if you know the folder name.
2. `find Zotero/storage -type d -name "*23BR*"` to find the folder name if you only know the partial of the folder name.
3. `find Zotero/storage -name "*keyword_from_title*.pdf"` to find the pdf file if you only know the keyword from the title.
